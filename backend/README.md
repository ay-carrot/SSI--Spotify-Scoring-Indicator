# SSI - Backend (API + CLI)

`backend/`には、FastAPIによるWeb API(`api/`)とCLI(`cli/`)の2つの入口があり、どちらも共有コア(`app/`)を呼び出します。
全体構成・コード構成・セットアップ・起動方法は、リポジトリルートの[`README.md`](../README.md)を参照してください。
ここでは、API一覧とCLIの使い方をまとめています。

**コマンドは、すべて`backend/`ディレクトリで実行してください**(`app`・`api`・`cli`パッケージを解決するため)。

## 目次

- [Web API版](#web-api版)
- [CLI版](#cli版)

## Web API版

### 起動

```bash
uvicorn api.main:app --reload --port 8000
```

初回起動時にテーブルが自動作成されます。
Swagger UIは起動後 `http://127.0.0.1:8000/docs` で確認できます。

### 主なAPI

| メソッド | パス | 説明 |
|---|---|---|
| GET | `/auth/login` | Spotify認可画面へリダイレクト |
| GET | `/auth/callback` | 認可コード受け取り、セッションCookie発行 |
| GET | `/auth/me` | ログイン中ユーザー情報 |
| POST | `/auth/logout` | ログアウト |
| GET | `/library/playlists` | 同期対象として選べるプレイリスト一覧(先頭に「お気に入り曲」を含む) |
| POST | `/library/sync` | 指定したプレイリスト(`playlist_ids`)を同期。未指定ならお気に入り曲のみ |
| GET | `/tracks/pair` | 指定プール(プレイリスト)内で対戦用の2曲を取得(`?playlist_id=...`必須) |
| POST | `/matches` | 対戦結果(`playlist_id`+`a_win`/`b_win`/`draw`)を送信、そのプール内のEloを更新 |
| GET | `/rankings` | 指定プール内のレーティング順一覧取得(`?playlist_id=...`必須) |
| GET | `/rankings/filters` | 対戦・ランキングで選べるプール(同期済みプレイリスト)の一覧を返す |

Cookieは有効でもDB上にユーザーが存在しない場合(DBを作り直した後の古いCookieなど)は、
`/auth/me`・`/library/*`は401を返します。

## CLI版

`app/services/`を直接呼ぶ、ターミナル版です。FastAPIサーバー(uvicorn)を起動していなくても、
PostgreSQLにさえ繋がれば単体で動きます。

**事前準備:** ルートの[`README.md`](../README.md)のセットアップ手順1(CLI用Redirect URIの追加を含む)・2・3・4を済ませてください。

### コマンド

#### メニュー形式(推奨)

```bash
python -m cli.main
```

状態遷移するメニューが表示され、ログイン状況に応じて選べる操作が変わります
(未ログイン時は「ログイン」のみ、ログイン後は「同期/対戦/ランキング/ログアウト」)。
番号を選ぶと該当機能を実行し、終わるとまたメニューに戻ります。

#### 個別スクリプトを直接実行することも可能

| コマンド | 役割 |
|---|---|
| `python -m cli.login` | Spotifyでログイン。ブラウザが開いて認可 → ローカルにログイン状態を保存 |
| `python -m cli.sync` | プレイリスト一覧を番号付きで表示し、選んだものを同期 |
| `python -m cli.battle` | 同期済みのプール(プレイリスト)を番号で選択 → 対戦ループ開始。`1`/`2`でどちらか選択、`d`で引き分け、`q`で終了 |
| `python -m cli.rankings` | プールを番号で選択 → そのプールのランキングを表示 |

ログアウトは、メニューの[4]から行います。ローカルのログイン状態(`~/.spotify_elo_cli/session.json`)だけを削除し、
DB上のSpotifyトークン自体は残ります。

### Web版との関係

- **DB・レーティングロジックは完全に共通**です。CLIで対戦した結果はWeb版のランキング画面にもそのまま反映されます(逆も同様)。
- ログイン状態はWeb版(Cookie)とCLI版(`~/.spotify_elo_cli/session.json`)で別々に管理されます。どちらかでログアウトしても、もう片方には影響しません。
- 同じPostgreSQLに繋がっている必要があります。
- Docker ComposeやApple containerでWeb版を動かしている場合は、DBのポートがホストの`127.0.0.1:5432`に公開されているので、
  `backend/.env`の`DATABASE_URL`をその宛先にしてCLIをホストで実行してください。
